# TerraNova / FerrAI CIC

TerraNova / FerrAI CIC is an auditable human–AI research-operations framework for turning living work into reviewed, versioned, public-safe, and citable artifacts.

> **Current maturity:** advanced prototype / active research workbench.
> This public repository is a bounded technical and evidence surface, not the live working core and not a finished SaaS product.

## Where to start

1. Read the [public artifacts index](docs/public/README.md) for an orientation to the released material.
2. Open the [architecture index](docs/architecture/README.md) for the public technical model.
3. Review the [public-boundary policy](docs/governance/public_boundary.md) before interpreting exports or mirrors.
4. Use the [Zenodo reference](docs/references/zenodo.md) when citing the work.

## Public three-layer architecture

| Layer | Public role |
|---|---|
| **Notion** | Living semantic source of record and governance context; not mirrored wholesale here |
| **GitHub** | Reviewed public-safe working state, technical trace, and release surface |
| **Zenodo** | Versioned, citable publication snapshots; published files remain fixed while descriptive metadata can be updated |

## What this repository contains

- Public-safe architecture, governance, scientific-concept, and reference documentation.
- Reviewed mirrors and derived artifacts whose source status is stated locally.
- Release packages, validators, tests, and reproducibility-oriented technical traces.
- Historical packages and dated audits retained with their original version and DOI context.

## Boundaries and non-claims

- This repository is not a wholesale export of the private working environment.
- No credentials or raw private workspace exports are intentionally published.
- Existing public identifiers and outbound reference URLs remain under public-safety review.
- Draft pull requests and review gates are intentional parts of the governance model.
- Conceptual models and axioms are not presented as empirical proof unless evidence is explicitly supplied.
- The framework makes no legal, medical, financial, investment, token, or NFT claim.
- It makes no claim of AI consciousness, personhood, independent authority, or unsupervised publication rights.
