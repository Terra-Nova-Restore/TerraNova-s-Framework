# NFSU2 Bayview laser map

Fan-made centerline vector of the **Need for Speed: Underground 2** Bayview road network, prepared for laser engraving/cutting experiments.

## File

- `NFSU2_Bayview_centerline_R2000.dxf`
- DXF: AutoCAD 2000 / R2000 (`AC1015`)
- Units: millimetres
- Layer: `MAP`
- Geometry: centerline `LWPOLYLINE` paths
- No text, logo, background plate, or decorative geometry

## Use

Created for engraving the Bayview road network into black MDF. Scale, laser parameters, material settings and post-processing are intentionally not encoded in the DXF.

The vector paths are a cleaned approximation of the visible reference map and are not an official game asset.

Need for Speed: Underground 2 and related names/assets are associated with their respective rights holders. This is a non-commercial fan-made project artifact.
