# TerraNova / FerrAI Scientific Core

This directory is the curated scientific and architectural core for TerraNova / FerrAI.

It is not a raw Notion dump. It is the GitHub-facing distillation layer for:

- mathematical and cybernetic foundations
- CIC / Cognitive Intelligent Cooperation
- CORE_GRID and deterministic system architecture
- trigger and codex modelling
- claim-to-evidence tracking
- Mermaid and ASCII diagrams
- LaTeX / dissertation-grade material

## Source boundary

Primary source index: `Notion Bibliothek.txt` uploaded in ChatGPT session, plus visible Notion/GitHub connector context.

Private raw notes, secrets, wallet data, identity keys, intimate material, unredacted chat exports, and shadow/archive-only material must not be committed here.

## Canonical import layers

1. `science/formulas` — formulas and formal models
2. `science/chapters` — dissertation chapters and theory backbone
3. `architecture` — CIC, CORE_GRID, SESSION_ROOT, system architecture
4. `evidence` — terminology, claim-to-evidence matrix, proof tracking
5. `diagrams` — Mermaid, ASCII and exported visual models
6. `sync` — Notion to GitHub mapping and validation
