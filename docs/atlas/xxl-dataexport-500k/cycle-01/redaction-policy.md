# Redaction Policy: XXL DatenExport 500k Cycle 01

Status: cycle-specific publication boundary
Scope: private 553,000-line corpus and derived safe repository artifacts

## Rule

The raw corpus is private evidence. It must not be committed to GitHub, pasted
inline into Notion, or uploaded to Zenodo.

## Allowed Repository Material

The repository may contain only:

- summaries
- manifests
- hash files
- safe indexes
- data-note drafts
- redaction policy
- aggregate metrics tables

## Disallowed Repository Material

Do not commit:

- raw dump files
- raw corpus excerpts
- full chat transcripts
- personal or account identifiers
- payment, wallet, key, seed phrase, credential, or token-secret material
- patent-sensitive implementation details
- private trigger canon or restricted internal operating mappings
- claims that are not marked as unverified or source-limited

## Promotion Gate

Before any additional material is promoted from this corpus, record:

- source artifact and hash
- derived artifact name
- reviewer
- classification label
- target layer
- redaction status
- patent / IP sensitivity status
- token / wallet / credential sensitivity status
- promotion decision

Default decision when uncertain: hold local/private and publish only aggregate
metadata.

## Cycle 01 Decision

Promotion decision: aggregate-only public-safe repository artifact.

No raw material was promoted in this cycle.
