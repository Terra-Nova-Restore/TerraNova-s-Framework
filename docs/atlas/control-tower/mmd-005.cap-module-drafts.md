## Hash Rule

Each draft hash is built from stable local material:

- visible reference
- working name
- source state
- runtime role
- CAP function
- activation surface
- guard evidence
- Atlas cluster/layer context
- boundary text

The hash changes if the draft material changes. It does not prove that the historical trigger definition is complete.
