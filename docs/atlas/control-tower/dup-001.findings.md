## Decision

`DUP-001` creates review queues only.

It does not decide which pages are duplicates in the destructive sense. A repeated title can mean any of these:

- a real duplicate
- a template copy
- an import artifact
- a work-in-progress page
- a current active hub with weak naming
- a sensitive dossier that must not be flattened

## Deterministic Boundary

Current Notion connector verification is required before any rename, move, archive or merge decision.

The raw `Home-Ansichten` snapshot remains local and sensitive. DUP artifacts expose aggregate queue structure only.
