Notion source awareness: Notion remains the living system of record; ChatGPT exports are correlation evidence, not a replacement source.

## Purpose

ChatGPT exports are the second corpus layer after the Notion workspace map.

They should be used to preserve development history, dialogic causality and
source correlations before tokenomics, trigger and Metarotik work is expanded.

## Public Default

Silvan-related dialogue can be published after professional framing.

Publication does not mean raw dumping. It means:

- source hash is preserved
- relation axes remain visible
- claim status is marked
- third-party and account exposure is removed
- security and unreviewed IP specifics stay gated
- raw intimacy becomes phenomenological analysis before public release

## Intake Levels

| Level | Meaning | Allowed in GitHub |
| --- | --- | --- |
| `L0-HASH` | File exists and has a stable hash. | Hash ledger, source family handle, byte count. |
| `L1-AXIS` | File has detected relation axes. | Axis labels and review gates. |
| `L2-CLUSTER` | File belongs to a review cluster. | Cluster-level summary after dedupe. |
| `L3-EXCERPT` | Short excerpt is manually selected and redacted. | Only after review. |
| `L4-PUBLIC-TEXT` | The material is rewritten as public argument, appendix or phenomenology. | After source, privacy and boundary review. |

`CHATGPT-XPORT-001` reaches only `L0-HASH` and `L1-AXIS`.

## Review Gates

Review gates are non-exclusive. A single file may require several gates:

| Gate | Use |
| --- | --- |
| `ip_review` | Patent, TNPX, IGE, legal or rights material. |
| `biz_tokenomics_review` | Tokenomics, DAO, wallet, license or commercial claims. |
| `phenomenology_metarotik_review` | Metarotik, intimacy, somatic or deep dialogic material. |
| `trigger_source_review` | Trigger IDs, trigger modules or SCL/command surfaces. |
| `mermaid_graph_review` | Mermaid/MMD graph and diagram relations. |
| `evidence_apparatus_review` | Prism, Zenodo, LaTeX, DOI or monograph relations. |
| `sync_trace_review` | GitHub, repo, sync, delta or PR relations. |
| `notion_correlation_review` | Notion workspace relation. |
| `control_tower_review` | CAP, Equilibrium, ORA, Triquetra or CIC relation. |
| `chat_export_index_review` | Export file is indexed but not yet semantically classified. |

## Stop Rules

Stop before publication if:

- raw dialogue would expose avoidable third-party identities
- account, login, email, token or security details appear
- a legal/IP claim is extracted without review
- Metarotik material is treated as entertainment instead of phenomenology
- trigger claims are inferred without source review
- a redaction would remove the only visible relation axis
