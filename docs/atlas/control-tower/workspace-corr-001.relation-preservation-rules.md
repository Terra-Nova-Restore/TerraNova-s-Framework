## Core Rule

Do not confuse privacy with flattening.

For TerraNova/FerrAI, the task is not to hide the path. The task is to preserve
the path in a form that is professionally accountable.

## Public Default

Silvan-related material can enter a public path when it is:

- source-aware
- professionally framed
- relation-preserving
- free of avoidable third-party exposure
- free of account or security exposure
- explicit about claim status and uncertainty

This includes deep conversations, metaphysical development, ORA/Triquetra
logic, Trigger relations, tokenomics relations, Mermaid relations and Metarotik
relations.

## Exceptions

The following remain redacted, abstracted or held until explicit review:

| Exception | Handling |
| --- | --- |
| Private third parties | Remove names and identifying details unless consent/public role exists. |
| Accounts | Remove emails, usernames, login surfaces, access paths and account screenshots. |
| Raw identities | Abstract unless the identity is Silvan's own deliberate public authorship context. |
| Intimate real names | Abstract or remove unless explicitly cleared. |
| Security material | Remove secrets, credentials, keys, operational security steps and exploitable details. |
| Unreviewed IP specifics | Preserve the relation; route details through patent/IP review first. |
