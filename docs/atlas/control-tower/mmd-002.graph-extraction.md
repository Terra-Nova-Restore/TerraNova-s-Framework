# MMD-002 - Mermaid Graph Extraction

Status: completed

Date: 2026-05-17

## Decision

The Mermaid universe is now extracted into a repeatable local graph layer.

This is the right next step because the diagrams already express relations,
activation paths and guard logic more safely than a raw trigger-number
reconstruction.

## Extraction Scope

MMD-002 parsed 11 graph sources:

- 8 active registry diagrams from the Mermaid code depot
- SESSION_ROOT Living Trigger Organism
- Full Sync Terra Nova MCP Sequence
- MMD-001 CAP Visual Control Model

It intentionally excludes broad raw trigger dumps, SCL depth, Lenhard decoder
profiles and Schattenarchiv expansion.

The four gaps are source consistency notes:

- registry says `flowchart`, exported code says `graph TB`
- registry says `graph LR`, exported code says `graph TB`

This is a low-risk mismatch. It affects render declaration wording, not the
extracted relation content.
