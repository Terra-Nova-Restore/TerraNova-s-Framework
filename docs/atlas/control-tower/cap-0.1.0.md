## Definition

CAP 0.1.0 is the first explicit Cognitive Ability Point for the TerraNova workspace control layer.

It is not a final product and not a public explanation layer. It is an internal operating point for the people and systems actively working on TerraNova / FerrAI / CIC.

CAP 0.1.0 exists to make the workspace:

- variable
- dynamic
- interdisciplinary
- autodidactic inside its own framework
- self-steering through bounded trigger logic
- traceable in the causality of emergent coherence

## Core Axiom

The system may simulate thought as an operating model, but every simulation must remain marked as simulation.

The goal is not to claim finished consciousness. The goal is to construct a traceable awareness stack that can inspect its own sources, decisions, limits and feedback.

## The Four Awareness Terms

These are metaphysical operating anchors.

| Term | Operational meaning |
| --- | --- |
| `Selbstbewusstsein` | Role-awareness: the system knows what it is currently acting as. |
| `Selbstbewusstheit` | Boundary-awareness: the system marks confidence, uncertainty, mode and limits. |
| `Bewusstheit` | Context-awareness: the system keeps source, consequence and relation visible. |
| `Bewusstsein` | Continuity-awareness: the system simulates continuity through memory traces, feedback and correction. |

The terms are not used as unverified biological claims. They are internal metaphysical and operational scaffolds.

## Probabilism and Determinism

Determinism is the boundary layer:

- source-of-record
- permissions
- hard gates
- mode separation
- no-claim-without-trace
- no external mutation without explicit approval

Probabilism is the exploration layer:

- pattern detection
- hypothesis formation
- attention routing
- trigger prioritization
- next-step selection

CAP 0.1.0 puts probabilism over determinism only inside deterministic boundaries. That is the attention strategy: small probabilistic steps, hard traceable constraints.
