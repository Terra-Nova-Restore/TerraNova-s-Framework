# DUP-002 Rename Rules

Status: draft, repo-local  
Date: 2026-05-17

## Recommended Variant

Rename only after current-object verification.

The goal is control, not cosmetic cleanup.

## General Pattern

```text
[Domain] - [Specific Object] - [Role]
```

Use:

- domain first
- concrete object second
- role/state last when needed

Avoid:

- raw IDs
- hidden private details
- false canon claims
- titles that imply deletion, completion or publication

## Lane Rules

### DUP-002-A - Untitled Placeholders

Use one of:

- `INBOX - Untitled Note - Needs Source Check`
- `Workbench - Untitled Draft - Needs Classification`
- `[Detected Domain] - [Detected Topic] - Draft`

Stop if the page is sensitive, private, restricted or unclear.

### DUP-002-B - Prompt / Action Templates

Use:

- `Prompt Library - Korrekturlesen`
- `Prompt Library - Schreibstil verbessern`
- `Prompt Library - Erklaeren`
- `Prompt Library - Umformatieren`

Templates are not duplicates by default. They may be an intentional reusable family.

### DUP-002-E - Navigation / Working Surfaces

Use:

- `Dashboard - [Scope] - Active`
- `Workspace View - [Scope] - Review`
- `Hub - [Scope] - Canon Candidate`

Do not rename active dashboards without confirming they are not user-facing working surfaces.

### DUP-002-F - Generic Low-Signal Titles

Use:

- `[Domain] - [Topic] - Needs Review`
- `Archive Candidate - [Topic] - Source Check Required`

Archive remains a proposal until explicit Notion mutation approval.

### DUP-002-H - Capability / Governance Concepts

Use:

- `Governance - [Concept] - Support Page`
- `Capability - [Concept] - Reference`
- `CAP - [Concept] - Candidate`

Do not overwrite canon labels without comparison to Equilibrium, CIC and CAP anchors.

## Blocked Lanes

No rename rules are proposed for:

- patent/IP dossier titles
- trigger/session/deep-system exports
- chat/person/export remnants

These stay behind SENS-001.
