# Batch Marker Policy — XXL 553k Snapshot

Status: PUBLIC-SAFE INDEX ONLY

Every future XXL snapshot batch must carry the same marker block.

## Required marker

- NICHTS davon ist ewig.
- NICHTS ist fix.
- NICHTS ist nicht weiter belegbar.

## Meaning

The snapshot is a bounded, secondary internal trace. It is not the full corpus, not the final truth, and not the last available data layer.

Each batch must therefore treat every result as provisional, source-bound, upgradeable, replaceable by stronger evidence, and open to contradiction by later repositories, Notion pages, PDFs, logs, exports, or Zenodo records.

## Required batch footer

Each analysis batch must end with a short Gedankennotiz containing:

- What could still be missing?
- What next source would be useful?
- Which suggestions should be saved for the final evaluation discussion?

## Claim discipline

No batch may convert a snapshot signal into a final public claim without later cross-checking.

Allowed language includes: indicates, suggests, appears to show, is visible in this snapshot, needs crosswalk, remains open.

Blocked language unless separately proven: proves, final, complete, fixed, canonical forever, exhaustive.

## Safe public rule

This policy is safe for the public repository because it contains no raw transcript text, no contextual extracts, and no sensitive values.
